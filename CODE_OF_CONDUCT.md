# Code of conduct

This project is for children. Be kind.

## Expected

- Talk about the product, the lesson, or the code.
- Assume good intent.
- Keep children's privacy. Never ask for or post a child's name, photo, school, or contact details.

## Not allowed

- Insults, harassment, or sexual content
- Sharing anyone's private contact details
- Pressure tactics aimed at children, including countdown clocks meant to rush them

## Reports

If someone breaks these rules, use the private security contact in SECURITY.md, or email the address published in that file's reporting instructions. Maintainers will look and may remove comments or block an account.

This is a short project code of conduct, written for GPS Kids / Tech GPS.
