# Contributing

GPS Kids Speak is developed in the open. Ideas, bug reports, and lesson drafts are welcome.

## Before you open an issue or a pull request

- Do not include a child's name, email, photo, school, or voice.
- Do not include a parent's email, phone, or a screenshot that shows one.
- Do not paste API keys, database ids, or admin codes.
- Describe the behavior you want in plain language.

## How to suggest a change

1. Open an issue with the template that fits: a feature idea, a bug, or a lesson idea.
2. For code, fork the repo and open a pull request against `main`.
3. Keep the kid-facing screens free of any AI vendor's name. Voice providers stay in server config.
4. Keep the soft progress ring. Do not add a visible countdown for kids.
5. Run `npm test` before you ask for review.
