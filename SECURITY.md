# Security

## Reporting a vulnerability

Please report security problems in private. Do not open a public GitHub issue for a secret, a child-data bug, or a way to skip the grown-up check.

Use GitHub private vulnerability reporting on this repository:

https://github.com/369Apps/gpskids-starter/security/advisories/new

If that page is not available yet, open a GitHub security advisory from the Security tab, or contact the maintainer through GitHub (Bobby, GPS Kids / Tech GPS) without pasting exploit details into a public issue.

## What to include

- What you tried and what you saw
- The page or file, if you know it
- No secrets, and no real child's or parent's personal information

## What we care about most

- Anything that collects a child's name, email, photo, or voice and stores it
- Anything that shows a secret from the server to the browser
- Anything that lets a child past the grown-up check into a parent form
